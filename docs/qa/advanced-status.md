## 已有验证依据

最终可重复命令和计数见 .local/reports/advanced-build/validation.json。

- 既有单元、协议、迁移与集成测试保留；新增多项目与 OIDC 集成。
- 两个空间四个项目的范围隔离；未知项目/非成员访问被拒绝；维护者不能隐式读成员私群。
- 分叉祖先水位、归档可读不可写、退出后的派生群撤权。
- 人工交接确认、防重放、依赖环拒绝、目标修订保留历史。
- 真实 Git 仓库、两个出站 WebSocket Bridge、独立 worktree、报告保存；独立步骤运行区间重叠，下游在两者结束后启动。
- 下游快照包含真实上游报告及哈希；执行结束仍等待人工集成核验。
- 未核清执行拒绝主节点切换；旧签名许可延迟到达时，在 worktree 准备之前被拒绝。
- OIDC 使用本地签名提供商，验证 PKCE、state、nonce、重放及未知账号拒绝。
- 桌面与手机视口客户流程覆盖空间/项目创建切换、讨论分叉、归档恢复及唯一侧栏；原聊天、提及、资料与历史继续回归。

真实 Pi 协议验证使用本机合成模型；DAG 并行验证使用明确标记“不调用 AI”的 inspection。两者不能被当成商业模型能力或企业质量指标。

## 使用与上线门槛

当前代码是可运行的进阶基础版本，P1/P2 的主要协作与执行链已接入单页，P3 身份和治理入口已搭建。完整进阶 PRD 的业务工具、隔离集群、生产高可用与质量目标仍未完成。

- 本轮没有修改用户已有 .env.local、密码、配对私钥或实际运行数据库；迁移在下次用户启动服务时应用。
- 数据库仅追加迁移，未修改已经发布的 0001～0006；默认项目沿用旧事实，默认执行并发保持 1。
- 多空间不等于 API 服务的高可用。控制面当前仍只运行一个实例。
- PostgreSQL schema 隔离、HTTPS/WSS 跨机、Docker 部署、备份恢复、50 人容量尚未在真实环境验收。
- OIDC 需用户登记企业客户端与回调；模型需实际可访问的配置。两团队两周试用和标注评测需要真实数据，代码不能替代。

运行与接口机制见 [进阶运行指南](../architecture/advanced-collaboration.md)。历史 MVP 记录见 [旧验证记录](implementation-status.md)，客户试用步骤见 [客户体验方案](customer-pilot.md)。

## 2026-10-19 注册与团队入驻补充

客户现在可以自行注册，创建团队及首项目，或通过邀请加入团队中的指定项目。聊天内“团队与项目”入口在桌面左栏和手机聊天头部均可使用。维护者支持设置邀请邮箱、名额、期限及撤销；新账号不再自动进入默认项目，重启亦不回填新身份。名册及根审计排除其他团队的身份／目录事件；项目撤权保留全站账号和其他团队资格，并拒绝旧任务继续派发、续租和回读。

新增 tests/integration/onboarding.test.ts 共 10 项，tests/e2e/onboarding.spec.ts 在桌面／手机各用两个独立会话验证注册、建团队、邀请、加入及聊天。原有数据保留、Pi、执行链及范围隔离继续回归；旧成员移除用例更新为项目撤权语义，验证个人会话仍有效但不能访问原项目。

验收依据见 .local/reports/onboarding/validation.json；客户操作与接口见 [账号与团队入驻](../architecture/team-onboarding.md)。MVP 和进阶需求的 MD／HTML 已分别补充 F01.1、A00。当前不包含邮件验证码、自动发信、找回密码和审批式入驻；不将邮箱字符串匹配宣称为企业身份验证。
