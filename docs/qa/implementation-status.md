> 进阶版已继续搭建，当前代码覆盖与边界以 [进阶状态](advanced-status.md) 为准。以下保留 MVP 阶段的历史记录。

## 已实现

| 能力               | 实现事实                                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 单页群聊           | 正式 React 页面；无任务中心／人工审批台必经路径；群聊导航常亮                                                        |
| 统一侧栏           | 上下文与共享资料只有一个入口并同时展示；成员、目标、来源、主设备复用唯一容器；可全关闭；标题固定、内容独立滚动       |
| 群生命周期         | 项目成员建公开／私有群，发现公开群、自主加入、24 小时群邀请码加入；旧项目会话保留可见性                              |
| 消息与提及         | 服务端序号、同成员 client_message_id 去重、UTF-8 大小限制；AI／当前群成员候选、稳定 ID、同名消歧、引用／代码屏蔽     |
| 草稿与历史         | 当前群、独立草稿与资料版本引用本机恢复；消息历史向前加载，保留滚动；旧长资料完整读取、乐观版本编辑                   |
| 持续观察           | 消息与 observation_jobs 同一事务；后台处理、连续观察水位、失败可见、手动重试、重启续处理；未配置模型时明确为规则模式 |
| 人工工作           | 候选→确认认领→共同工作索引→附证据自报完成；自报完成不冒充代码验证                                                    |
| 重复协调           | 精确效果键覆盖全部已登记历史；项目协调行锁与唯一约束原子认领；人工／Agent／已完成工作参与比对                        |
| 模型理解与比对端口 | 可选 OpenAI 兼容 JSON 适配器；有权工作候选、来源版本与约束比较；模型不能修改权限；匹配目标版本和具体字段须服务端复核 |
| 自动判断           | 有效明确委托在设备策略内批准并生成受限许可；重复拒绝关联既有工作；含糊／相近目标先澄清；复核后的具体差异可形成新执行 |
| 停止               | 群成员按钮或明确 @AI 停止某目标；先存停止意图，待 Runner 停止证据后终结；未知原执行继续占槽；停止不回滚文件          |
| 主设备语义         | Owner 表示服务器设备；人类维护者配置策略。原账号 OWNER 标识与 OWNER\_\* 初始化变量保留兼容，不表示逐次人工审批       |
| 策略版本           | 绑定仓库、基线、工具、目录、预算、受众、策略版本；策略变更使旧排队许可失效，并停止活动旧许可／拒绝续租               |
| 执行与成果         | 复用真实 Bridge、SQLite、签名、独立 worktree、Pi RPC 和受控工具；新协调目标成果自动按原群权限展示                    |
| 权限与迁移         | 私群不因维护者身份开放；v1 列表、详情、消息、统计与保留接口补齐群 ACL；追加迁移导入旧工作，未修改用户运行数据或凭据  |

## 当前边界与后续必做

1. 完成真实模型配置与标注评测：规则模式仅处理明确模式，语义比对仍需真实团队评测；当前模型输入使用近期 20 条消息与最多 50 个有权工作候选，候选总字符预算 20000。精确重复查询不受候选分页影响，但不能宣称语义召回覆盖全部项目历史。
2. 补齐所有群生命周期与撤权场景、完整通知／未读系统、目标／资料大规模分页、已确认记忆的成员协作治理和迁移审计 UI。当前群、目标、资料列表各有首批上限，历史底层 API 仍保留。
3. 观察器按单 Owner API 实例运行；重启恢复 processing 作业，不支持多副本观察器抢占／租约。目标更新与执行认领已有事务保护，但不能据此声称控制面高可用。
4. 对 Pi 真实企业模型、代码编辑验收、branch／会话分叉、冲突集成、摘要质量和重启／网络故障继续做真实验证。
5. PostgreSQL 实例、HTTPS/WSS 多机、容器部署、备份恢复、长期运行、磁盘与并发负载尚未完整验收。
6. 既有云端保留默认关闭；新观察作业和目标事件尚未接入完整归档策略。本机账本／worktree 不自动清理。没有启用实际数据清理。
7. 本轮不提供任意 Shell、自动推送／部署、多项目多 Owner、DAG 并行或新建／删除文件工具。代码编辑仍受既有 Pi 工具的精确替换边界约束。

运行与配置见 [README](../../README.md)，本轮机制见 [群聊协调架构](../architecture/chat-coordination.md)。

## 2026-10-19：Pi 工具可维护性与客户体验准备

- guard-extension.ts 仅负责读取权限清单、注册获准工具及安装守卫；四个工具分别放入 tools/filesystem 和 tools/context。
- tool-policy.ts 为 CLI、注册表、会话守卫提供同一工具清单，注册表用类型检查约束工具实现完整性。
- 工具 label、description 和参数 description 使用中文；Pi、Bridge、协调器、聊天请求、账本和上下文边界补充中文注释。协议名称及错误码保持兼容。
- Pi 合约测试现在通过真实 CLI 调用四个工具，覆盖授权原文回读、未授权来源不触达回读服务、文件范围、编辑前缀、中文描述与请求预算。
- 本轮 82 项单元/集成/协议测试、4 项桌面/手机视口浏览器场景、类型、目录边界、正式构建和打包冒烟全部通过。
- 客户试用文档的独立数据启动方式已额外验证：新 PGlite、真实维护者登录、Web 页面和 v2 群聊入口，未向现有用户库注入试用数据。
- 多设备试用仍需完成 HTTPS 验收。当前 Web 使用 crypto.randomUUID，普通局域网 HTTP 不作为完整客户体验入口；物理手机与异地网络未在本轮验证。
- 说明见 [Pi 调用链](../architecture/pi-tool-chain.md)、[客户体验方案](customer-pilot.md)。本轮机器可读记录位于 .local/reports/pi-tools-refactor/validation.json。
